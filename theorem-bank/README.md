## Strong structural spine

The program progressively isolates where finite fiber coherence becomes genuinely harder:

- forest incidence: exact support-message criterion;
- unicyclic incidence: support failure or fixed-point/monodromy failure;
- cactus incidence: exact block-cut message criterion;
- cycle rank two: theta path-relation intersection classification;
- cycle rank three: exactly four branch kernels after suppressing degree-two paths;
- fixed cycle rank: parameterized tractability;
- unbounded cycle rank: a source-claimed NP-completeness frontier;
- #595 interface: finite frustration core versus exact coherent Berge-`C3` compression.

The bank also preserves negative theorems: ordinary quotient structure alone is sterile; bounded local coherence tests fail; arc consistency is insufficient; one-step repair information can collapse; finite high-complexity civilizations can remain countably decomposable.

## Claim discipline

This release intentionally publishes conjectural and target material alongside theorem-shaped material, but does not conflate them. Read the labels. The terminal rank-four and higher-order repair programs remain open targets. No claim here is promoted merely because it belongs to a coherent theory.
